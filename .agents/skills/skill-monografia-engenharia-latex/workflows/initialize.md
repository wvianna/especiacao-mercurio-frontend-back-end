# Workflow — Inicialização

1. Auditar o workspace.
2. Localizar modelo institucional e orientações do curso.
3. Ler arquivos de controle existentes.
4. Identificar tema, problema, objetivos e estágio atual.
5. Identificar documentos, código, dados, imagens e referências relevantes.
6. Criar ou atualizar a estrutura LaTeX.
7. Criar arquivos de controle se ausentes.
8. Registrar lacunas em `MONOGRAFIA_PENDENCIAS.md`.
9. Não mover arquivos sem autorização.
10. Atualizar `MONOGRAFIA_STATUS.md`.
