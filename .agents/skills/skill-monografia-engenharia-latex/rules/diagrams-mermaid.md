# Regra — Diagramas Mermaid

Usar Mermaid somente quando melhorar a compreensão do sistema ou processo.

Manter fontes em `diagrams/` e gerar artefatos compatíveis com LaTeX.

Todo diagrama deve:
- possuir identificação e legenda adequadas;
- ser citado no texto;
- ter função explicativa;
- permanecer coerente com a arquitetura real.

Não criar diagramas decorativos para atingir a meta de páginas.
