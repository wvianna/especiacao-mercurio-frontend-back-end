# Definition of Done

Uma tarefa só pode ser considerada concluída quando aplicável:

- [ ] Requisito relacionado identificado.
- [ ] Critérios `CA-###` verificados.
- [ ] `git diff` executado antes da alteração.
- [ ] Código alterado no menor escopo necessário.
- [ ] Build do alvo executado.
- [ ] Testes executados.
- [ ] Análise estática/formatador executados quando aplicáveis.
- [ ] RAM/flash/stack/timing verificados quando aplicáveis.
- [ ] Documentação atualizada.
- [ ] Rastreabilidade atualizada.
- [ ] `STATUS.md` atualizado se houve mudança significativa.
- [ ] `HANDOFF.md` atualizado somente se houver continuidade.
- [ ] Riscos residuais registrados.
- [ ] Nenhuma alteração não relacionada foi incorporada.
